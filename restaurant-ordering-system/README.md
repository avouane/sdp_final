# Restaurant Ordering System

Учебный командный проект на Java. Этот репозиторий пока содержит только структуру и пустые исходные файлы — реализации ещё нет.

## Состав команды

| Участник | Файлы и зона ответственности | Паттерны |
|---|---|---|
| Студент 1 | `catalog/`, `pricing/` | Factory, Strategy |
| Студент 2 | `cart/`, `orders/command/` | Decorator, Command |
| Студент 3 | `orders/model/`, `orders/state/`, `notifications/observer/`, `app/` | State, Observer |

Распределение путей исходников и критерии интеграции: `student-work/`.

## Предварительные сценарии

1. Посмотреть меню и выбрать блюда.
2. Настроить блюдо добавками и размером.
3. Применить ценовую стратегию и собрать корзину.
4. Оформить заказ.
5. Отслеживать переходы заказа по статусам; кухня и клиент получают уведомления.

## Структура

- `src/main/java/` — исходники, оставленные пустыми до начала реализации.
- `src/test/java/` — место для тестов.
- `docs/uml/` — UML-диаграммы для защиты.
- `docs/screenshots/` — скриншоты работающего приложения для отчёта.
- `docs/report_outline.md` — план отчёта по требованиям защиты.

## Запуск

Сборочная конфигурация и реализация приложения пока не добавлены. Добавьте их после согласования версии Java и способа сборки.
