# План отчёта к защите

Заполнить после реализации проекта. По требованиям защиты отчёт должен содержать:

1. Введение: проблема, цель и задачи проекта.
2. Основную часть: архитектура, сценарии, обоснование и взаимодействие минимум шести паттернов.
3. UML-диаграммы.
4. Скриншоты работающего приложения.
5. Исходный код проекта.
6. Заключение.
7. Дальнейшую работу (Further work).

Перед сдачей экспортировать отчёт в PDF; исходный код подготовить отдельным ZIP-архивом.
